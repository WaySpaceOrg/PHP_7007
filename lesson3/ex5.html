ทดลองคำนวณ BMI ✨

ฝึกใช้ JavaScript รับค่าจาก input ตรวจสอบข้อมูล แปลงหน่วยส่วนสูงจากเซนติเมตรเป็นเมตร และคำนวณตามสูตร BMI เพื่อเรียนรู้การทำงานของตัวเลขและเงื่อนไข

🌷 สิ่งที่จะได้เรียนรู้

ฝึกอ่านค่า ตรวจสอบข้อมูล และคำนวณด้วย JavaScript

📖 💜
⌨️

รับค่าและตรวจสอบข้อมูล

อ่านค่าจากช่อง input ด้วย value และตรวจสอบว่าผู้ใช้กรอกข้อมูลครบถ้วนและเป็นตัวเลขที่มากกว่าศูนย์

🧮

คำนวณด้วยสูตร

แปลงส่วนสูงจากเซนติเมตรเป็นเมตร แล้วทดลองใช้การคูณและการหารเพื่อหาค่าตามสูตร

💻 ทดลองคำนวณจากสูตร

กรอกตัวเลขตัวอย่างเพื่อเรียนรู้การทำงานของสูตร แล้วกดปุ่มคำนวณ

ใช้เป็นค่าตัวอย่างสำหรับการทดลองสูตร
ระบบจะแปลงเป็นเมตรก่อนคำนวณ
ผลการคำนวณตามสูตร BMI—

กรอกข้อมูลตัวอย่างแล้วกดคำนวณ

ข้อควรรู้: BMI เป็นเพียงค่าคำนวณเบื้องต้น ไม่ใช่การวินิจฉัยสุขภาพ สำหรับเด็กและวัยรุ่น การแปลผลต้องพิจารณาอายุและเพศร่วมกับกราฟการเจริญเติบโต และควรปรึกษาบุคลากรทางการแพทย์ ไม่ควรใช้ตัวเลขนี้ตัดสินรูปร่างหรือคุณค่าของตนเอง

🧁 ตัวอย่างโค้ด JavaScript

const weight = Number(document.getElementById("weight").value);
const heightCm = Number(document.getElementById("height").value);

const heightM = heightCm / 100;
const bmi = weight / (heightM * heightM);

document.getElementById("result").textContent = bmi.toFixed(1);

💡 toFixed(1) ใช้แสดงผลตัวเลขทศนิยม 1 ตำแหน่ง
