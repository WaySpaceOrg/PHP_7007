สุ่มข้อความ กำลังใจ 🌸

เรียนรู้การใช้ Array เพื่อเก็บข้อความหลายรายการ และใช้ Math.random() ร่วมกับ Math.floor() เพื่อสุ่มเลือกข้อความมาแสดงบนหน้าเว็บไซต์

🌷 สิ่งที่จะได้เรียนรู้

ฝึกใช้ Array และการสุ่มค่าด้วย JavaScript

📖 💜
📚

Array · อาร์เรย์

ใช้เก็บข้อมูลหลายรายการไว้ในตัวแปรเดียว เช่น รายการข้อความให้กำลังใจที่สามารถเลือกมาแสดงได้

🎲

Math.random()

ใช้สุ่มตัวเลข แล้วนำ Math.floor() มาปัดเศษลง เพื่อให้ได้ตำแหน่งลำดับของข้อมูลใน Array

🎀 กล่องสุ่มข้อความกำลังใจ

กดปุ่มเพื่อสุ่มรับข้อความดี ๆ สำหรับวันนี้

🌷 ข้อความดี ๆ สำหรับคุณ ขอให้วันนี้เป็นวันที่สดใส!

ทุกก้าวเล็ก ๆ คือความก้าวหน้า 💗

💻 ตัวอย่างโค้ด JavaScript

const fortunes = [
  "วันนี้จะเป็นวันที่ดี",
  "คุณทำได้แน่นอน",
  "ค่อย ๆ เรียนรู้ ไม่ต้องรีบ",
  "อย่าลืมภูมิใจในตัวเอง",
  "ทุกความพยายามมีความหมาย"
];

const i = Math.floor(Math.random() * fortunes.length);
document.getElementById("fortune").textContent = fortunes[i];

💡 Math.random() สุ่มค่าตั้งแต่ 0 ถึงน้อยกว่า 1 ส่วน fortunes.length คือจำนวนรายการทั้งหมดใน Array
