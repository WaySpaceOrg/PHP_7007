ปุ่มกด ถูกใจ 💗

ฝึกใช้ JavaScript จัดการเหตุการณ์คลิก (click event) และตัวแปร let เพื่อเพิ่มจำนวนการกดถูกใจ พร้อมตรวจสอบเงื่อนไขด้วย if...else

🌷 สิ่งที่จะได้เรียนรู้

ฝึกเขียนคำสั่งให้หน้าเว็บตอบสนองต่อการคลิก

📖 💜
👆

Event Listener

ใช้ addEventListener("click", ...) เพื่อสั่งให้โปรแกรมทำงานเมื่อผู้ใช้กดปุ่ม

🔢

ตัวแปรและเงื่อนไข

ใช้ let เก็บจำนวนครั้งที่กด และใช้ if...else ตรวจสอบว่าจำนวนครบ 10 ครั้งหรือยัง

🎀 ทดลองกดปุ่มถูกใจ

กดปุ่มด้านล่างเพื่อเพิ่มจำนวนถูกใจ ลองกดให้ครบ 10 ครั้งนะคะ!

0ครั้งที่กดถูกใจ

เริ่มกดถูกใจได้เลย ✨

💻 ตัวอย่างโค้ด JavaScript

let likes = 0;
const btn = document.getElementById("like");

btn.addEventListener("click", function () {
  likes = likes + 1;
  document.getElementById("count").textContent = likes;

  if (likes >= 10) {
    console.log("ยอดนิยมแล้ว!");
  } else {
    console.log("อีก " + (10 - likes) + " ครั้ง");
  }
});

💡 addEventListener ช่วยให้เรากำหนดการทำงานเมื่อเกิดเหตุการณ์ต่าง ๆ เช่น การคลิกปุ่ม ส่วน if...else ใช้เลือกทำงานตามเงื่อนไข
