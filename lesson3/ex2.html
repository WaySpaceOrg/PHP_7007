🦋 LESSON 03 · EXERCISE 02

ฝึกคำนวณ ราคารวม 🧁

เรียนรู้การรับค่าจากช่องกรอกข้อมูลด้วย JavaScript และนำค่ามาคำนวณราคา โดยใช้ตัวอย่างการซื้อสินค้าจากร้านกาแฟแมวเหมียว

🌷 สิ่งที่จะได้เรียนรู้

การอ่านค่าจากหน้าเว็บและนำมาคำนวณ

📖 💜
🏷️

อ่านค่าราคา

ใช้ document.getElementById() เพื่อเลือกข้อมูลจากหน้าเว็บ และใช้ textContent อ่านข้อความราคา

🔢

แปลงค่าและคำนวณ

ใช้ Number() แปลงข้อความให้เป็นตัวเลข จากนั้นคูณราคาต่อชิ้นกับจำนวนสินค้า

💻 ทดลองคำนวณราคาสินค้า

ลองเปลี่ยนจำนวนสินค้า แล้วกดปุ่มคำนวณเพื่อดูผลลัพธ์ค่ะ

☕ เมนูร้านกาแฟแมวเหมียว
ราคาต่อแก้ว
45 บาท
ยอดรวมทั้งหมด135 บาท

💡 สูตรคำนวณ: ราคาต่อแก้ว × จำนวนที่สั่ง เช่น 45 × 3 = 135 บาท

🧁 ตัวอย่างโค้ด JavaScript

คำสั่งสำคัญที่ใช้ในการคำนวณ

const price = Number(document.getElementById("price").textContent);
const qty = Number(document.getElementById("qty").value);

const total = price * qty;
document.getElementById("total").textContent = total + " บาท";

สังเกตว่า value ใช้อ่านค่าจากช่อง input ส่วน textContent ใช้อ่านหรือเปลี่ยนข้อความภายใน element
