🦋 LESSON 03 · EXERCISE 01

JavaScript ตัวแรก ✨

เริ่มต้นเรียนรู้ JavaScript ผ่านตัวอย่างร้านกาแฟแมวเหมียว ทำความรู้จักตัวแปร const และ let พร้อมทดลองดูผลลัพธ์จากคำสั่ง console.log()

🌷 สิ่งที่จะได้เรียนรู้

พื้นฐานเล็ก ๆ ที่สำคัญสำหรับการเขียน JavaScript

📖 💜
🔒

const · ค่าคงที่

ใช้ประกาศตัวแปรที่ไม่ต้องการกำหนดค่าใหม่ เช่น ชื่อร้านกาแฟ ซึ่งยังคงเป็นชื่อเดิม

🔄

let · ตัวแปรที่เปลี่ยนค่าได้

ใช้ประกาศตัวแปรที่สามารถเปลี่ยนแปลงค่าได้ เช่น จำนวนแก้วกาแฟที่ขายไปแล้ว

💻 ตัวอย่างโค้ด

JavaScript
const shop = "ร้านกาแฟแมวเหมียว";
let cups = 3;

console.log("ร้าน: " + shop);
console.log("ขายไปแล้ว " + cups + " แก้ว");

cups = cups + 1;
console.log("ตอนนี้ " + cups + " แก้ว");
ผลลัพธ์จะแสดงที่นี่ เมื่อกดปุ่มทดลองรัน ✨

💡 เคล็ดลับ: เปิด Developer Tools แล้วเลือกแท็บ Console เพื่อดูผลลัพธ์จากคำสั่ง console.log() ได้เช่นกัน

🧁 สรุปแบบเข้าใจง่าย

จำให้ได้ว่า const และ let ใช้ต่างกันอย่างไร

📌 const

เหมาะกับค่าที่กำหนดแล้วไม่เปลี่ยน เช่น ชื่อร้าน

📌 let

เหมาะกับค่าที่อาจเปลี่ยนภายหลัง เช่น จำนวนสินค้าที่ขายได้
